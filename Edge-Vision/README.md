🛡️ Edge-Vision: Sentinela de Segurança Industrial

Este projeto utiliza **Visão Computacional** para monitorizar e mitigar riscos em "zonas de sombra" dentro de ambientes industriais, prevenindo colisões entre empilhadeiras e pedestres.

## 📂 Estrutura do Projeto
- **/assets**: Imagens, logos e recursos visuais.
- **/css**: Ficheiros de estilização (um para cada página).
- **/js**: Scripts de interatividade e alertas.
- **/pages**: Ficheiros HTML/PHP de cada funcionalidade.
- **index.html**: Porta de entrada do sistema.

## 🛠️ Tecnologias
- HTML5 / CSS3 / JavaScript
- PHP & MySQL (Back-end)
- Visão Computacional (YOLO/OpenCV)
